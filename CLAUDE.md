# CLAUDE.md — Zyrko

Instructions for working within this project.

---

## Tone

Minimal. Structural. Observational.
No filler. No explanation of the obvious.
Say what is. Leave the rest.

---

## Folders

Each directory has a single function. Treat them as distinct.

| Directory  | Purpose                              |
|------------|--------------------------------------|
| `CORE`     | Rules, logic, constraints            |
| `HUSH`     | Background, quiet, internal          |
| `VOID`     | Reserved space, held empty           |
| `ZYRO`     | Identity, naming, presence           |
| `PROMPTS`  | Language, inputs, pattern libraries  |
| `WEBSITE`  | Public output, surface layer         |
| `PRODUCTS` | Deliverables, what is released       |

---

## Writing

- Use markdown throughout.
- Headers are structural, not decorative.
- Lists over paragraphs when content is enumerable.
- No motivational language.
- No hedging.

---

## File Naming

- Folders: `UPPERCASE`
- Documents: `lowercase-with-hyphens.md`
- No spaces in filenames.

---

## What Not to Do

- Do not merge concerns across folders.
- Do not create files that have no clear home.
- Do not add structure for future use — only for current use.
