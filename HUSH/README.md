# HUSH

Quiet operations. Not meant to be seen.

---

## What this holds

- Background processes
- Internal tooling
- Automations that run without announcement
- Systems that support without surfacing

---

## Properties

- Nothing in HUSH is user-facing
- HUSH does not speak first
- Outputs from HUSH feed other folders silently
