# Zyro Prompt Base v1

Status: active
Created: 2026-07-09
Use: prepend or adapt this block whenever an image generation request uses Zyro.

## Base Guardrail

```text
Zyro is not a newly designed logo. Treat the canonical Zyro SVG as the visual source. Do not redesign the silhouette. Preserve the black infinity-shaped field, one continuous white Orbit, restrained left spiral, single convergence crossing, empty right Void chamber, horizontal 2:1 structure, and binary black/white logic.

The right Void chamber must remain a plain dark field enclosed only by the continuous Orbit. Do not add a crescent, partial inner line, extra arc, eye highlight, decorative stroke, circular recess, circular depression, inner oval ring, dish-like pit, or mechanical round plate.

Use image generation for atmosphere, scene, material context, lighting, and composition. Do not rely on image generation as the sole source for official Zyro logo, font glyph, icon, or production asset. When exact fidelity matters, render or composite the canonical SVG afterward.
```

## Canonical Keywords

```text
canonical Zyro glyph, black infinity-shaped field, single continuous white Orbit, restrained left spiral, single convergence crossing, empty right Void chamber, plain dark negative space, 2:1 horizontal mark, no extra inner line, no circular recess
```

## Negative Keywords

```text
redesigned logo, generic infinity mark, multiple white lines, extra spiral, extra symbol, eye, lens, circular recess, circular depression, oval pit, crescent, partial stroke, decorative crack inside the right chamber, mechanical plate, inner ring, glowing orb inside the right chamber
```

## Review Reminder

After generation, check:

- Does it still read as Zyro, not generic infinity?
- Is the Orbit one continuous trajectory?
- Is the right chamber a plain dark field?
- Are there no circular recesses or extra inner marks?
- Is the left spiral restrained, not ornamental?
