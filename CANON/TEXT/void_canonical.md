# VOID



VOID is an unresolved center.



VOID is NOT:



* darkness

* evil

* a portal

* symbolic emptiness

* destruction



VOID is:



* attraction

* held absence

* unresolved depth

* structural incompleteness



---



## Structural Role



VOID functions as:



* convergence center

* unresolved attractor

* phase instability anchor



VOID should not provide narrative explanation.



VOID should preserve:



* ambiguity

* depth

* structural tension



---



## Visual Manifestation



Visual manifestation may appear:



* black

* depth-like

* absorptive

* spatially unstable



However:

blackness itself is NOT the definition of VOID.



VOID should not become:



* decorative

* glowing fantasy imagery

* symbolic iconography

* simplified darkness metaphor

* structurally unresolved
