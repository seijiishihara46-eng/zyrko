# Zyro Essence Canon

Status: active essence clarification
Created: 2026-07-09
Scope: Zyro concept, visual generation, glyph/illustration distinction

## Core Memory

The remembered core Zyro form is:

```text
left spiral + right droplet + one-stroke trajectory
```

This is the **Zyro Essence** layer.

It should not be confused with the reduced font/glyph implementation that was created so Zyro can function as a typographic character.

## Layer Distinction

### 1. Zyro Glyph / Font Canon

Purpose:

- make Zyro typeable;
- make it work as a small icon / font glyph;
- reduce the shape to minimum reproducible elements;
- preserve a stable silhouette for U+E000 and derived assets.

Current implementation:

- black infinity-shaped field;
- one continuous white Orbit;
- restrained left spiral;
- right Void chamber;
- 2:1 horizontal glyph structure.

This is a **compressed typographic form**.

### 2. Zyro Essence / Visual Canon

Purpose:

- preserve what Zyro means visually and mythologically;
- guide illustration, wall relief, atmosphere, Hush face, relic, poster, and image generation;
- allow material and expressive variation without losing identity.

Essential structure:

- left spiral;
- right droplet;
- one-stroke trajectory;
- convergence between the two sides;
- Orbit moving toward / touching / implying Void;
- asymmetry, not a generic mathematical infinity sign.

This is the **visual-conceptual form**.

## One-Stroke Rule

The one-stroke rule belongs to the Orbit / trajectory logic.

It means:

```text
Zyro should feel like a single continuous movement from left spiral through convergence into the right droplet/Void side.
```

It does **not** mean every production asset must be a literal single SVG path with no fill.

For glyph/font assets, the one-stroke logic is compressed into a white Orbit channel over a black field.

For illustration/image-generation assets, the one-stroke logic can be expressed as a carved groove, luminous channel, engraved flow, wall relief, or animated trace.

## Right Droplet Rule

The right side is remembered as a droplet, not merely a circular loop.

Allowed visual interpretations:

- droplet-like Void mass;
- dark teardrop chamber;
- asymmetrical right lobe;
- quiet negative-space weight;
- black field that feels pulled or suspended.

Avoid:

- generic perfect oval;
- circular recess;
- camera lens / eye;
- mechanical disk;
- symmetric infinity loop;
- decorative right-side ornament.

## Left Spiral Rule

The left side carries the spiral identity.

Allowed variation:

- exact spiral count may vary in illustration;
- material may alter the edge;
- carved / glowing / relief expression may differ;
- hand-drawn or ancient-wall versions may be less mathematically precise.

Do not lose:

- the left side must read as spiral-origin behavior;
- the spiral must connect to the one-stroke trajectory;
- it must not become arbitrary decoration detached from Zyro.

## Image Generation Rule

When generating visual or illustrative Zyro images:

```text
Preserve the essence: left spiral, right droplet, one-stroke trajectory, convergence, asymmetry, and Void weight.
The exact spiral curvature may vary, but the right side must not become a circular recess, eye, lens, or generic loop.
The output should not collapse into a generic infinity logo.
```

## Relationship To Existing Glyph Canon

The existing `zyro-glyph-canonical.svg` remains valid as the **typeable glyph canon**.

However, for image generation and visual worldbuilding, the glyph canon should be treated as a compressed derivative of the broader essence:

```text
Essence Canon: left spiral + right droplet + one-stroke trajectory
Glyph Canon: compressed black-field + white Orbit implementation for font/icon use
Visual Canon: illustration/scene expression that preserves the Essence Canon
```

## Practical Usage

Use Glyph Canon when the output must be:

- font;
- icon;
- UI mark;
- small symbol;
- official minimal logo;
- exact SVG export.

Use Essence / Visual Canon when the output is:

- wall relief;
- scene concept;
- ancient relic;
- Hush face;
- poster;
- 3D surface;
- cinematic image generation;
- stylized brand artwork.

## Final Principle

Zyro should not become merely a clean infinity symbol.

Zyro is:

```text
left spiral
right droplet
one-stroke movement
convergence
Void weight
```

The glyph is the reduced sign. The essence is the identity.
